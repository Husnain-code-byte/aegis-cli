## ADR Template (MADR Format)
For new ADRs, use `/adr-write [title]` or create manually:

```markdown
# [Short title of solved problem and solution]

* Status: proposed | accepted | deprecated | superseded
* Deciders: [names]
* Date: [YYYY-MM-DD]

## Context and Problem Statement
[2-3 sentences describing the situation and forces at play]

## Decision Drivers
* [driver 1]
* [driver 2]

## Considered Options
* [option 1]
* [option 2]
* [option 3]

## Decision Outcome
Chosen option: "[option X]", because [justification].

### Consequences
* Good, because [positive consequence]
* Bad, because [negative consequence — explicitly name what we gave up]

## Pros and Cons of the Options
### [option 1]
* Good, because [argument]
* Bad, because [argument]
```
