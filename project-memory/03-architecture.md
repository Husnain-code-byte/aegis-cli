## Architecture Principles
1. **API-first:** contract defined before implementation
2. **Stateless services:** no server-side session state
3. **Eventual consistency where acceptable:** strong consistency only when required
4. **Defense in depth:** security at every layer
5. **Observability built-in:** every service emits traces, metrics, and logs
6. **Fail gracefully:** circuit breakers, retries with backoff, graceful degradation
